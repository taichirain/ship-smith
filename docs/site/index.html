ShipSmith 项目概览

ShipSmith

部署自动化 + Feature Flag 控制平面。

简介

ShipSmith 是一个轻量级的部署自动化和 Feature Flag 管理工具。

- 一键部署：从 Git 仓库自动部署到你的服务器

- 即时回滚：一键回滚到任意历史成功版本

- Feature Flag：控制功能开关，无需重新部署

- Agent 架构：轻量 Agent 在目标服务器运行，与控制平面解耦

快速开始

1. 启动数据库

确保 PostgreSQL 运行在 localhost:5432，创建数据库：


createdb shipsmith

2. 运行 migration


bash dev.sh db-init

3. 启动 Core API


bash dev.sh start-api

API 文档: http://localhost:8000/docs

4. 启动 Web Panel


cd apps/web
npm install
npm run dev

访问: http://localhost:3000

默认账号: admin / admin123

目录结构


shipsmith/
├── apps/
│   ├── web/          # Next.js 管理面板
│   └── api/          # FastAPI Core API
├── packages/
│   ├── config/        # 共享配置和协议定义
│   ├── db/            # 数据库模型和 migrations
│   ├── agent/         # 部署 Agent
│   └── sdk/           # Node.js Feature Flag SDK
├── docs/
│   ├── PRD.md
│   └── user-guide/   # 用户手册
└── dev.sh             # 开发脚本

环境变量

变量说明默认值 `DATABASE_URL`数据库连接字符串`postgresql://postgres:postgres@localhost:5432/shipsmith` `JWT_SECRET_KEY`JWT 签名密钥`change-me-in-production-please` `ADMIN_USERNAME`管理员用户名`admin` `ADMIN_PASSWORD`管理员密码`admin123`

开发


# 同时启动 API 和 Web
bash dev.sh all

# 打包 Agent 二进制
bash dev.sh package-agent 1.0.0
